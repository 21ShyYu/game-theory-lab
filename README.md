# 丢手绢博弈游戏 (Drop the Handkerchief Game)

## 📋 项目简介

这是一个基于博弈论的互动游戏，模拟了经典的"丢手绢"游戏场景，通过信息不对称和心理博弈来展现策略决策的复杂性。玩家将与AI进行对抗，体验攻守转换和策略选择的乐趣。

## 🎮 游戏规则

### 基础规则
- **回合制**：每轮游戏包含10个回合
- **角色**：攻方（丢手绢）和守方（查杀）
- **初始血量**：双方各40点HP
- **攻守互换**：每轮结束后双方角色互换
- **胜利条件**：对方血量归零

### 三种结算情况

#### 1️⃣ 间隔伤害
- **触发条件**：攻方已丢下手绢，守方延迟回头查杀
- **伤害计算**：守方扣除 `(当前回合 - 丢手绢回合)` 点血量
- **示例**：攻方第3回合丢下手绢，守方第7回合才查杀 → 守方 -4 HP

#### 2️⃣ 误判
- **触发条件**：守方回头查杀时，攻方尚未丢下手绢
- **伤害**：守方 -10 HP
- **特殊机制**：若守方拥有护盾，第一次误判免疫伤害

#### 3️⃣ 识破
- **触发条件**：守方在攻方丢下手绢的同一回合查杀
- **伤害**：守方 +5 HP（回血），攻方 -10 HP
- **说明**：这是守方最理想的结果

### 🛡️ 护盾机制（残血保护）
- **触发条件**：当守方血量低于20点时，自动获得一次护盾
- **效果**：第一次误判时免疫伤害，游戏继续
- **消耗**：护盾仅抵消误判伤害，识破或间隔伤害时不消耗
- **提示**：拥有护盾时会显示金色图标 🛡️

### 🎯 策略要点
- **攻方**：选择合适的时机丢下手绢，太早或太晚都可能被识破或造成较少伤害
- **守方**：判断攻方的行动模式，在合适的时机回头查杀
- **信息不对称**：攻方知道手绢位置，守方需要猜测
- **血量上限**：回血不会超过40点上限

## 🚀 使用方法

1. 直接在浏览器中打开 `Handkerchief.html` 文件
2. 游戏会随机分配初始角色（攻方或守方）
3. 根据当前角色选择行动：
   - **攻方**：选择"丢下"或"持有"手绢
   - **守方**：选择"回头"查杀或"继续走"
4. 每轮10回合结束后，攻守互换
5. 直到一方血量归零，游戏结束
